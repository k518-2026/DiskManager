ディスク管理ツール

ドライブの健康診断、パーティションの作成と削除、フォーマット、安全な取り外し、 古い CD / DVD のバックアップ。ひとつの画面から扱えるようにまとめたツールです。

01起動と権限

このツールはディスクを直接操作するため、必ず管理者権限で動きます。 起動すると Windows の確認（UAC）が一度出ますので、「はい」を選んでください。

起動のしかた

  • DiskManager.exe をダブルクリック
  • Visual Studio から実行する場合は Ctrl+F5（F5 だとデバッガーの都合で権限の確認が二重になります）

権限があるかを確かめる

画面左上、タイトルの右に 管理者として実行中 と出ていれば正常です。 管理者権限がありません と表示されている場合は、S.M.A.R.T. の読み取り、 パーティション操作、フォーマット、取り外しのすべてが失敗します。 いったん閉じ、実行ファイルを右クリックして「管理者として実行」で起動し直してください。

最初に確認

操作したいドライブに大事なデータが残っていないか、先に確かめてください。 このツールの多くの操作は元に戻せません。各操作の説明には 戻せない のようなバッジを付けてあるので、 実行前に目印にしてください。

02画面の見かた

画面は 4 つの領域に分かれています。

領域役割
左側の一覧 つながっている物理ディスクが並びます。ここで選んだディスクが、右側すべてのタブの操作対象になります。各項目には型番、容量・種類・接続方式、ドライブ文字、健康状態のバッジが出ます。
右側のタブ 目的ごとに 6 つ。概要 / 健康状態 / パーティション / フォーマット / CD・DVD / 取り外し・ツール。
下部の進捗バー 実行中の処理と進み具合。長い処理はここで残量を確認します。
実行ログ 行った操作と結果がすべて時刻付きで残ります。「ログを保存」でテキストファイルに書き出せます。

共通のボタン

ボタン動作
再スキャンディスクとボリュームの一覧を取り直します。ケーブルを挿し直したあとなどに使います。
中止実行中の処理を止めます。読み取り検査やコピーは安全に止まりますが、フォーマットの途中で止めるとボリュームは使えない状態になります。

03概要タブ

選んだディスクの素性と、中がどう区切られているかをひと目で見るための画面です。 ここでは何も変更されません。まずこのタブで対象が合っているかを確かめてから、他のタブに移ってください。

レイアウトの帯

パーティションが容量に比例した幅で並びます。色と枠の意味は次のとおりです。

—500 MB
EFI
C:400 GB
基本データ
D:180 GB
基本データ
未割り当て120 GB

橙の枠 = システム／起動領域（保護対象）　·　緑・青の枠 = 通常のパーティション　·　灰 = 未割り当て領域

帯にマウスを重ねると、開始位置と種類が出ます。 未割り当てと表示されている部分は、まだどのドライブにも属していない空き領域です。 ここに新しいパーティションを作れます。

ボリューム一覧

このディスクの中でドライブ文字が付いているものを一覧にします。使用率のバーは、 空き容量がどれだけ残っているかの目安です。「保護（システム）」と付いた行は、 このツールでは削除もフォーマットもできません。

04健康状態タブ

ドライブ自身が内部に記録している劣化の記録（S.M.A.R.T.）を読み出して、 まだ使い続けてよいかを判定します。

健康状態を取得 読み取りのみ 数秒

ディスクを選んでボタンを押すだけです。ドライブには何も書き込みません。 気になったときに何度でも実行できます。

判定の見かた

判定意味と、どうすべきか
良好 重大な劣化の兆候はありません。通常どおり使えます。
注意 代替処理済セクタがある、温度が高いなど、劣化の始まりが見えています。すぐ壊れるとは限りませんが、バックアップの間隔を短くしてください。
不良 読み取り不能な領域が出ている、またはドライブ自身が故障予測フラグを立てています。新しい書き込みをせず、いますぐ他のドライブにデータを退避してください。
取得不可 このドライブは S.M.A.R.T. を公開していません。USB 変換ブリッジ経由の外付けや一部の NVMe で起こります。故障を意味しません。

特に見ておきたい項目

属性見かた
05 代替処理済セクタ数読めなくなったセクタを予備と入れ替えた回数。0 が理想。増え続けているなら寿命が近い。
197 代替処理保留中セクタ数読めなくなったが、まだ入れ替えられていないセクタ。1 以上なら要注意。
198 回復不可能セクタ数訂正できなかったエラー。1 以上ならデータの一部はすでに失われている可能性がある。
194 温度55 ℃ を超えていたら冷却の見直しを。
09 使用時間累積の通電時間。HDD は 3〜5 万時間あたりから交換を意識する目安になります。

属性一覧の読みかた

「現在値」は 100 や 200 から始まり、劣化するほど下がります。これが「しきい値」を下回った属性が ひとつでもあると、判定は不良になります。「生の値」は回数や時間などの実数で、 属性によって単位が違います。

05パーティションタブ

ディスクの中を区切り直す画面です。ここから先はデータが失われる操作が含まれます。

新しいパーティションを作る

  1. 左の一覧で対象のディスクを選びます。
  2. 概要タブの帯で、未割り当て領域があることを確かめます。
  3. 空き全部を使うなら「空き領域をすべて使う」にチェック。一部だけなら外して MB 単位でサイズを入れます（10 GB なら 10240）。
  4. ドライブ文字を選びます。(自動) のままなら Windows が空いている文字を割り当てます。
  5. 「作成する」を押します。
  6. できたパーティションはまだ未フォーマットで使えません。続けてフォーマットタブへ進みます。
パーティションを作成 既存データは無事 数秒

未割り当て領域を使うだけなので、他のパーティションの中身には触れません。

選択したパーティションを削除 戻せない 数秒

一覧で選んだパーティションを消し、そこを未割り当てに戻します。中のデータは失われます。 システム／起動パーティションは選んでも削除できません。

未使用ディスクを初期化 中身が消える 数秒

買ったばかりのディスクや、Windows が「初期化されていません」と言うディスクに管理情報を書きます。 GPT が既定です。2 TB を超えるディスクや UEFI 環境では GPT を選んでください。 古い機器との互換が必要なときだけ MBR にします。

ディスクを消去 戻せない 数秒〜数時間

ディスク上のパーティションをすべて削除します。「消去時に全域へゼロを書き込む」に チェックを入れると、加えて全領域にゼロを書き込むため復元は極めて困難になりますが、 容量に応じて数時間かかり、途中で止められません。譲渡や廃棄の前に使ってください。

そのほかの操作

ボタン使う場面
ドライブ文字を割り当てエクスプローラーに出てこないパーティションに文字を付けます。選択中のパーティションが対象です。
オンライン / オフライン切替「オフライン」と表示されるディスクを使える状態に戻します。もう一度押すと逆になります。
読み取り専用を解除書き込もうとすると拒否されるディスクの属性を外します。物理的な書き込み禁止スイッチがある場合は、そちらも確認してください。

06フォーマットタブ

ドライブを使える状態に整えます。3 つの方式があり、目的で選び分けます。

どれを選ぶか

方式かかる時間選ぶ場面
簡易フォーマット 数秒 自分で使い続けるドライブ。中身を空にしたいだけのとき。データは復元ソフトで読み出せる状態のまま残ります。
通常フォーマット 数十分〜数時間 調子が怪しいドライブを使い直すとき。全セクタにゼロを書きながら不良セクタを検査します。
ディープフォーマット 数時間〜 人に譲る、売る、捨てる前。ゼロ・1・乱数を指定回数（1〜7 回）書き込み、復元を困難にします。

手順

  1. 「対象のドライブ」で、フォーマットするドライブを選びます。選ぶと下に警告が出て、失われる容量が示されます。
  2. 方式を選びます。ディープを選んだときは上書き回数も指定します（3 回で実用上十分です）。
  3. ファイルシステムを選びます。迷ったら下の表を参照してください。
  4. 必要ならラベル（ドライブの名前）を入れます。日本語も使えます。
  5. 「フォーマットを実行」を押し、確認画面にドライブ文字（例: E）を入力します。

ファイルシステムの選びかた

形式特徴
NTFSWindows で使う内蔵・外付けドライブの標準。迷ったらこれ。
exFATWindows と Mac の両方で読み書きしたい USB メモリや外付け HDD 向け。4 GB 超のファイルも扱えます。
FAT32カーナビ、ゲーム機、古い機器向け。1 ファイル 4 GB までという制限があります。
ReFS大容量向けの新しい形式。対応環境が限られるため、必要と分かっているときだけ。

「クラスタサイズ」は通常「既定」のままで構いません。小さいファイルが大量にあるなら小さく、 動画のような大きなファイル中心なら大きくすると、わずかに効率が上がります。

ラベルだけ変更 中身はそのまま 即座

フォーマットせずに、ドライブの表示名だけを変えます。

空き領域だけ上書き 既存ファイルは残る 数十分〜数時間

いま入っているファイルは残したまま、過去に削除したデータの痕跡だけを消します。 「消したはずのファイルを復元されたくないが、いま使っているドライブは空にしたくない」というときに使います。

SSD の場合

ディープフォーマットは SSD の代替ブロックまでは消せません。SSD を確実に消してから手放したいときは、 メーカーが配布するツールの Secure Erase を併用してください。

07CD / DVD タブ

古いディスクがまだ読めるかを調べ、読めるうちに中身を救い出すための画面です。 傷や経年劣化で一部が読めなくなっていても、処理は途中で止まりません。

メディアを確認 読み取りのみ 数秒

ラベル、ファイルシステム、ファイル数、合計サイズ、更新日の範囲を表示します。中身の見当をつけるのに使います。

全セクタを読み取り検査 読み取りのみ 5〜30 分

先頭から末尾まで全部を実際に読んで、読めないセクタの数を数えます。保存はしません。 「読み取り再試行」の回数を増やすと、粘って読める確率が上がる代わりに時間が延びます。 結果が良好ならまだ健全、劣化ありなら急いでバックアップしてください。

バックアップの 2 つの方法

ISO イメージとして保存 読み取りのみ 5〜30 分

ディスクを丸ごと 1 個のファイルにします。読めなかったセクタはゼロで埋めて位置を保つので、 壊れかけのディスクでも最後まで通ります。 起動ディスクやゲームなど、ファイルをコピーするだけでは再現できないものはこちらを選んでください。

できた .iso は、Windows でダブルクリックすると仮想ドライブとしてマウントでき、 中のファイルをそのまま取り出せます。

ファイルをフォルダーへコピー 読み取りのみ 5〜30 分

中のファイルをそのままフォルダーへ取り出します。写真や書類のバックアップ向きです。 読めなかったファイルはスキップして続行し、保存先に _読み取り失敗ファイル一覧.txt を残します。

迷ったら

劣化が進んでいそうなディスクは、まず ISO で丸ごと吸い出すのが安全です。 ISO さえ手元にあれば、中身の取り出しは後からいつでもできます。 ディスクを何度も読むこと自体が劣化を進めるため、読む回数は少ないほうが有利です。

「トレイを開く」「トレイを閉じる」でドライブの開閉ができます。 スロット式のドライブでは「閉じる」が効かないことがあります。

08取り外し・ツールタブ

安全に取り外す

安全に取り外す データは保たれる 数秒

書き込み待ちのデータを完全に書き出してから、ボリュームのマウントを解除し、 USB 機器そのものを停止します。この操作が成功したあとなら、ケーブルを抜いて構いません。

「使用中です」と拒否された場合、ログに理由が出ます。よくあるのは次の 2 つです。

  • アプリケーションが拒否 — そのドライブのファイルを開いているアプリや、エクスプローラーのウィンドウを閉じてから再試行してください。
  • ページングファイル使用中 — そのドライブが仮想メモリに使われています。システムの設定で解除が必要です。

ハードウェアを再認識

抜き差ししても現れないドライブがあるときに押します。デバイスマネージャーの 「ハードウェア変更のスキャン」と同じことをしたうえで、ディスクの再スキャンも行います。 認識されない外付けドライブは、これで復帰することがあります。

diskpart（上級者向け）

この画面にない操作を、Windows 標準の diskpart のコマンドで直接実行できます。 1 行に 1 コマンドで書いてください。

コマンド例内容
list diskディスクの一覧を表示
select disk 1
list partition		ディスク 1 を選び、そのパーティションを表示
select disk 1
convert gpt		ディスク 1 を GPT に変換
select disk 1
attributes disk clear readonly		読み取り専用属性を解除

diskpart の注意

clean / delete / format などが含まれる場合は確認画面が出ますが、 それ以外に安全装置はありません。ディスク番号を必ず list disk で確認してから 実行してください。番号を間違えると、意図しないディスクが消えます。

09安全のしくみ

取り返しのつかない操作を防ぐため、次の仕組みを入れてあります。

システム領域は操作できない

Windows が入っているドライブと起動用パーティションは、削除・フォーマット・消去・取り外しの 対象から自動的に外れます。ボタンを押しても実行されず、ログにその旨が出ます。

対象名の入力を求める確認

データが失われる操作の前には、対象の名前を手で入力する画面が出ます。 「はい」を連打して事故が起きることを防ぐためです。

操作入力する文字
パーティションの削除削除
ディスクの消去ディスク1（対象の番号）
フォーマットE（対象のドライブ文字）
ディスクの初期化初期化

すべてログに残る

実行した内容と結果は時刻付きで下部のログに残ります。「ログを保存」で書き出しておくと、 あとから何をしたか確認できます。うまくいかなかったときの原因調べにも役立ちます。

10困ったときは

症状対処
操作がすべて「アクセスが拒否されました」になる 管理者権限で起動していません。画面左上の表示を確認し、右クリック →「管理者として実行」で起動し直してください。
健康状態が「取得不可」になる 故障ではありません。USB 変換ブリッジ経由の外付けや一部の NVMe は S.M.A.R.T. を外に出しません。可能なら本体に直接つないで試してください。
つないだ USB メモリが一覧に出ない 「再スキャン」→ それでも出なければ「ハードウェアを再認識」。それでも出ない場合は別のポートを試してください。
「安全に取り外す」が拒否される そのドライブを使っているアプリ（エクスプローラー、ウイルス対策ソフト、開いたままのファイル）を閉じて再試行してください。ログに拒否した理由が出ます。
作ったパーティションがエクスプローラーに出ない 作成直後は未フォーマットです。フォーマットタブでフォーマットしてください。ドライブ文字が付いていない場合は「ドライブ文字を割り当て」を先に実行します。
フォーマットが「ボリュームを開くことができません」で失敗する そのドライブを他のアプリが使っています。使用中のアプリを閉じるか、いったん取り外して挿し直してから再試行してください。
フォーマットが終わらない 通常フォーマットとディープフォーマットは容量に比例して時間がかかります。数 TB のディスクなら数時間が普通です。進捗バーが動いていれば正常に進んでいます。
CD の読み取りが極端に遅い 読めないセクタで再試行を繰り返しています。時間を優先するなら「読み取り再試行」を 1 に下げてください。救出を優先するなら回数を増やしたまま待ちます。
ディスクが「読み取り専用」になっている パーティションタブの「読み取り専用を解除」を実行します。SD カードなど、本体に書き込み禁止スイッチがある場合はそちらも確認してください。

11用語

用語意味
物理ディスク装置としての 1 台。HDD や SSD、USB メモリそのもの。
パーティション1 台の物理ディスクを区切った領域。1 台を C: と D: に分ける、といった使い方をします。
ボリュームフォーマットされ、ドライブ文字が付いて使える状態になった領域。
未割り当て領域まだどのパーティションにも属していない空き。ここに新しいパーティションを作れます。
MBR / GPTディスクの区切りかたを記録する方式。GPT が新しく、2 TB 超に対応。MBR は古い機器向け。
S.M.A.R.T.ドライブが自分の劣化具合を記録しているしくみ。読み出すことで故障の予兆が分かります。
セクタディスク上の最小の読み書き単位。CD / DVD では 2048 バイト。
代替処理済セクタ読めなくなったため、予備の領域と入れ替えられたセクタ。数が増えるほど寿命が近い。
ISO イメージCD / DVD の中身を丸ごと 1 個のファイルにしたもの。ダブルクリックで仮想ドライブとして開けます。
クラスタサイズファイルを置くときの区画の大きさ。既定のままで問題ありません。
